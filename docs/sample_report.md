# Sample findings (synthetic data)

The bundled CSV contains five fictional project records. The report is intended to demonstrate how simple indicators can be calculated; it is not a real project assessment.

After running the script, check `outputs/analysis_report.csv` for row-level calculations and `outputs/budget_comparison.png` for the budget chart.

Questions to investigate:
- Which projects are forecast to finish after their planned end date?
- Which projects are over their planned budget?
- Which projects have actual progress below planned progress?
- Do budget and schedule indicators tell the same story for every project?

Do not infer project success from a single metric. The tool does not model scope changes, uncertainty, project complexity, or official evaluation criteria.
